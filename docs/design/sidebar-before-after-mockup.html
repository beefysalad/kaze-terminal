The rules behind "After"

  • Group header: repo name and a count, or "N waiting" in amber. No dots.
  • Line 1: state dot, agent logo, then the name: your kaze name → the title the agent set (Claude's summary or /rename) → the folder's name, only if it differs from the repo → the program (codex, zsh). The word "claude"/"codex" is gone; the logo says it.
  • Line 2: the branch and its +/− counts. In a worktree: ⑂ worktree-name · branch (just the branch if the two match).
  • Gone: the folder path line, the header dots, the "Next waiting" button (Cmd+J still works).
  • Status on the right of line 1: "needs you", "done", or the agent count while running.
