Sidebar, where and how wide

Built from today's Kaze (a headless render of the current sidebar and title bar): filter field, repo groups with a bold name and count, two-line rows with the state mark, agent logo, status and branch with line counts, the agent tray, and Workspaces at the bottom. Same sessions in every window.

My pick: one side setting, and the rail follows it.

A new setting chooses left (today's default) or right. Cmd B then cycles full, rail, hidden, and the rail always sits on the same side as the sidebar. So it is two choices, side and width, and every combination works the same way. Part 1 shows those four windows. Part 2 has the other ideas.
