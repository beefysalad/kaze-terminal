# Kaze logo refinement proof

Status: proposed design, awaiting owner review.

Retain the existing wind K identity and lilac palette. Give the stem a slight forward taper, separate the two sweeping arms with a deliberate gap, and use flat muted lilac. Set the lowercase wordmark in Manrope Medium with tighter optical spacing and a small JetBrains Mono byline. All lettering is outlined, so the SVG has no runtime font dependency.

The proof shows the lockup at display size and a 136 by 55 pixel header size. The logo SVG has a transparent background for the dark lander. This is a dark-background variant.

After design approval, propose the integration plan for the lander header, footer and favicon. Existing branding assets and landing pages have not been replaced. App icons and binaries are outside this lander proof.
