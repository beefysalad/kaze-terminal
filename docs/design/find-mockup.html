How it works

  • Ctrl Shift F (Cmd F on Mac) opens find in whatever has the keyboard: Claude’s terminal or a docked tab. Plain Ctrl+F stays with the shell.
  • Searches the whole scrollback, not just the screen. Matches are tinted violet; the current one is amber, and the view scrolls to it.
  • Enter / ↓ next, Shift+Enter / ↑ previous, Aa case-sensitive, Esc closes and returns to where you were.
  • Marks on the right edge show where every match sits in the scrollback, like an editor’s scrollbar.
  • Opening find again keeps the last search, selected, so you can type over it.

Cost

  • Nothing runs while the bar is closed.
  • It searches once per change of the text (and again when new output arrives while it’s open), capped at 1,000 matches.

Decided for you (say if you disagree)

Case-insensitive by default, with Aa to switch. No regex in the first version.
Terminals and docked tabs first. The markdown reader and the agent panel come later.
New output while searching updates the count but doesn’t jump the view; the current match stays put.
