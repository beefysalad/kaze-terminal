# Folded K terminal vector artwork

Hand-built SVG reconstruction of the accepted `../concepts/04-folded-k-dev.png` concept, 2026-11-16. This is editable vector artwork, not an embedded PNG. The silhouette and terminal underscore are preserved; raster lighting is simplified into a restrained violet gradient for clean scaling.

- `kaze-mark.svg`: transparent standalone mark.
- `kaze-logo.svg`, `kaze-logo-light.svg`: full outlined wordmark and byline.
- `kaze-lockup.svg`, `kaze-lockup-light.svg`: compact wordmark without byline.
- `kaze-icon.svg`: full app tile for favicon and Windows export.
- `kaze-app-icon-macos.svg`: icon with macOS canvas margins.
- `proof.svg`, `proof.png`: dark/light and 128, 64, 32, 16 pixel review.
- PNG files are previews exported from the vectors using resvg, not source artwork.

Dark palette: #b9a6ff to #8b7bff. Light contrast palette: #7962d8 to #6048bd. Tile: #242034 to #100e1d. All lettering is outlined with no external font requirement.

Validation: all SVGs parse as XML and contain no image, text, script or foreignObject elements; exports and proof visually inspected. Production assets have not been replaced. Rollout plan: `../../../superpowers/plans/2026-11-16-kaze-folded-dev-branding.md`.
