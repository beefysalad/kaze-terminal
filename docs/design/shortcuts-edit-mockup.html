How it works

  • Click a shortcut: it waits for keys. Press them and it saves. Esc cancels; the old keys stay.
  • Taken by another action: it asks. Replace moves the keys here and leaves the other action with none (still in the palette).
  • Keys your shell or Claude Code use (plain Ctrl+letter on Windows): saved, with a one-line warning.
  • No modifier (a plain letter, Enter, Esc, Tab): refused, the old keys stay.
  • A changed shortcut gets a "changed" tag and a reset arrow. "Reset all to defaults" asks first.
  • Mouse gestures stay read-only.
