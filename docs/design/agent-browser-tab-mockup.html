The idea

  • The agent's browser runs headless: no window, so it can never pop in front of you while you type (Windows run, 2026-11-04).
  • Kaze shows its page as a Browser tab in the panel under the terminal, next to your servers and subagents.
  • One browser per session, its own clean profile. It starts on the agent's first browser call or when you type a URL here.

In the tab

  • Live page with back, forward, reload and the address. A violet box shows where the agent just clicked or typed.
  • Who's driving: "Agent browsing" while it acts; "You" after you click. You can always click, scroll and type in the page.
  • Console and network on the right, errors counted.
  • Send to agent: pick screenshot, URL, console errors, failed requests or an element; they land in Claude's prompt as attachments, ready for you to add a sentence and send.
  • Pick an element: hover to highlight, click to attach its selector, text and a cropped screenshot.
  • Open in my browser opens the same URL in your normal browser.

Cost

  • Nothing until first use. The page only draws while the tab shows; hidden, Kaze receives no frames.
  • About 280 MB per running browser (Chrome), shown in the status bar. Closes with its session or after 10 idle minutes and reopens on the next call.

Decided for you (say if you disagree)

Send to agent fills the prompt but doesn't send, so you can add a sentence first. Enter sends as usual.
Idle close after 10 minutes without agent calls or you looking at the tab.
Chrome if installed, else Edge (Chrome is about 30% lighter).
