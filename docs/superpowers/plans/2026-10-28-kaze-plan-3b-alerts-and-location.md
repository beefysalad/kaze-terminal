# kaze Plan 3b: Attention alerts, chime, and folder/branch in the status bar

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When Claude Code in any tab finishes or needs the owner, that tab is marked, a toast says so (with a chime for "needs you"), and the status bar shows the active tab's folder and git branch.

**Architecture:** Two independent tracks.
- **Alerts:** kaze listens on `127.0.0.1:<random port>` with a random token. Each tab's shell gets `KAZE_NOTIFY` (address) and `KAZE_NOTIFY_TOKEN`. Claude Code hooks run `kaze notify <kind>`, which reads the hook JSON from stdin and sends `{token, tab, kind, reason}`. The UI marks the tab, shows a toast, plays a chime per config.
- **Location:** the shell reports its folder with OSC 7 from its prompt; the Applier stores it per tab. kaze reads the branch from `.git/HEAD` (no git process) whenever the folder is reported. The status bar shows `~\path  ⎇ branch`.

**Tech Stack:** Go 1.27, Gio v0.10.3, stdlib `net`, `encoding/json`; Windows `winmm.dll` `PlaySoundW` via `syscall` (no cgo); macOS `afplay`.

**Spec:** `docs/superpowers/specs/2026-10-28-kaze-terminal-design.md` sections 6.4 and 6.8 (decisions), 6.7 (colors). Mockup: `docs/design/titlebar-and-status.html`.

## Global Constraints

- Alert kinds: exactly two, `done` (Claude Code `Stop` hook) and `needs` (Claude Code `Notification` hook: permission prompt or waiting for input). No transcript guessing.
- Transport: TCP on `127.0.0.1` only (never `0.0.0.0`), port 0 (OS-chosen), 32-byte random token (hex) checked on every message; messages over 4KB or with a bad token are dropped. One JSON object per connection, read deadline 2s.
- Env per tab: `KAZE_NOTIFY=127.0.0.1:<port>`, `KAZE_NOTIFY_TOKEN=<hex>`, plus existing `KAZE_TAB_ID`.
- `kaze notify` must never block or fail Claude Code: 1s total timeout, exit 0 on any error, no output on stdout.
- Tab marks: `needs` = amber dot `#f2b84b`; `done` = green dot `#62d39a`. **No pulsing animation** (idle CPU must stay ~0). The mark clears when the tab becomes active while the window is focused.
- Toast: bottom-right, above the status bar, `#1a1f2c` with `#2a3142` 1dp border, 10dp radius, text `#e7e9f0`, "<tab title> needs you · <reason>" or "<tab title> is done", plus "Go ›" (accent `#b9a6ff`) that switches to that tab. `needs` toasts stay until visited or dismissed (click ×); `done` toasts auto-hide after 6s (one scheduled invalidate, no ticker). Max 3 toasts stacked; newest on top.
- No alert UI or chime when the event's tab is the active tab and the window is focused.
- Chime: bundled `assets/sounds/chime.wav` (generated by a small Go tool in `tools/chime`, license-free, ~0.4s, soft two-tone, 44.1kHz 16-bit mono, < 64KB). Plays for `needs` by default, silent for `done`. Several alerts within 1s give one chime.
- Config (`config.toml`): `chime_needs` (bool, default true), `chime_done` (bool, default false), `chime_file` (path, default empty = bundled). Unknown/invalid values warn as today.
- Folder: OSC 7 `file://<host>/<path>`; percent-decoded; Windows paths arrive as `/C:/Users/...` and become `C:\Users\...`. Shown with the home prefix replaced by `~`. Branch: from `HEAD` `ref: refs/heads/<name>` → `<name>`; detached → first 7 hex chars; walk up parents to find `.git` (dir) or `.git` file with `gitdir: <path>` (worktrees/submodules); give up at the filesystem root or after 64 levels. No repo → no branch shown.
- Status bar left side: `<folder>  ⎇ <branch>` (folder `#c9cdd8`, branch `#62d39a`), then the existing right side unchanged. Truncate the folder from the left with "…" if needed.
- Installing the Claude Code hooks into `~/.claude/settings.json` and the OSC 7 snippet into the owner's shell profile is NOT done by any task. Tasks only document the snippets (README). The owner approves and the coordinator installs.
- Safety: never inject global input; RED tests bounded; commits `type(scope): Verb ...`, no AI attribution.

## Review Focus

1. **Another local program sends fake alerts** → dropped unless the token matches (A1 test `TestRejectsBadToken`).
2. **kaze is closed while Claude runs** → `kaze notify` exits 0 quickly, Claude is unaffected (A2 test `TestNotifyWithoutServerExitsQuietly`).
3. **Alert for a tab that was closed** → ignored, no toast, no panic (A3 test `TestAlertForUnknownTabIgnored`).
4. **OSC 7 with spaces / Japanese in the path** → decoded correctly (B1 test `TestOSC7DecodesPercentAndUTF8`).
5. **Huge or hostile `.git` layouts** (gitdir loops, unreadable HEAD) → no hang, no branch (B2 test `TestGitdirLoopStops`).
